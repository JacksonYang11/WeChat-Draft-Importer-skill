# 故障排查

## 动态 IP 与白名单

`doctor` 或 `import` 返回退出码 4 时，JSON 会带微信实际识别的 `observed_ip` 和 `settings_url`。打开页面把该 IP 加入白名单、完成管理员扫码后重跑即可。白名单已包含出口时不需要每天修改；换宽带、热点或代理可能改变出口。程序不自动扩大访问权限，也不用公共 IP 查询网站猜测微信出口。

## 凭证问题

退出码 3 时按顺序检查：默认配置是否存在、密钥文件是否存在且非空、权限是否为 600、是否传错 `--config`。这些检查只返回存在性和权限，不显示凭证值。已有配置不要重新运行 `configure`；权限或路径错误先修原文件。确实缺失或已更换凭证时，由本人在本地终端补充，不在聊天中粘贴密钥。

## 退出码

| 退出码 | 意义 | 下一步 |
| --- | --- | --- |
| 0 | 本命令成功；doctor 仅验证读取 | 检查 JSON status，不混淆只读与已导入 |
| 2 | 输入、依赖或格式错误 | 修正文稿/图片，或运行 setup.sh |
| 3 | 凭证缺失或权限不正确 | 本人终端配置，不在聊天粘贴密钥 |
| 4 | IP 白名单不符 | 按 observed_ip 手动更新并扫码 |
| 5 | 网络/HTTP/响应异常 | 查看 pending，禁止盲目重传 |
| 6 | 微信业务拒绝 | 按 wechat_code 核对权限/配额/密钥 |
| 7 | 同篇正在被其他进程处理 | 等该进程完成 |
| 8 | 更新冲突、后台有改动或文件已存在 | 人工判断，禁止隐式覆盖 |
| 9 | 上次写入结果不确定 | reconcile 或人工核查 |
| 10 | 草稿存在但回读核验失败 | 查看 checks，不声称成功 |

## 写入结果不确定（退出码 9）

不要清除状态、修改 article_id 或循环重跑来绕过。草稿写入可用 `reconcile <目录>` 只读核查并接管唯一匹配稿；素材上传结果不确定时停止并人工核查，程序不会盲目重传。

## 草稿已发表或被删除

检测失败、草稿已发表或删除、回读不一致时不会报告成功，也不会自动新建替代稿。若确实需要新稿，请重新创建交接包及 article_id。
